BioGPT-ClinVar

Parameter-Efficient Biomedical Language Model for Genomic Variant Interpretation

Status: ✅ Completed

Category: Genomic AI & Foundation Models

Description:

BioGPT-ClinVar is a reproducible computational research project exploring the adaptation of Microsoft BioGPT for genomic variant interpretation using ClinVar data and LoRA-based parameter-efficient fine-tuning. The project implements an end-to-end pipeline covering genomic data preparation, instruction dataset construction, train/validation/test splitting, parameter-efficient model adaptation, evaluation, and inference.

Key Contributions:

  • Fine-tuned Microsoft BioGPT (150M parameters) using LoRA
  • Developed a structured instruction-tuning dataset from ClinVar
  • Applied parameter-efficient fine-tuning
  • Released trained model for reproducible research
